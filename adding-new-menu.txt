==================================================================
  دليل إضافة قائمة / صفحة جديدة إلى نظام شؤون الطلاب
==================================================================

القاعدة الأساسية:
  - القوائم والصلاحيات كلها في ملف واحد:  config/menu.php
  - كل صفحة تبدأ بالسطر  guard();  فتُحمى تلقائيًا بحسب ما هو مكتوب في menu.php
  - لا تعدّل header.php ولا ملف الاستايل style_2.css عند إضافة قائمة


------------------------------------------------------------------
أولًا: إضافة صفحة جديدة بقائمة مباشرة (3 خطوات)
------------------------------------------------------------------

مثال: صفحة "التقارير" يراها مدير النظام وشؤون الطلاب فقط.

الخطوة 1) أنشئ مجلد وملف الصفحة:
          reports/index.php

          وضع فيه هذا القالب:

----------------------------------------------------------------
<?php
declare(strict_types=1);
require __DIR__ . '/../includes/bootstrap.php';
guard();                                   // الحماية تلقائية من menu.php

$pageTitle    = 'التقارير';                // عنوان الصفحة
$pageSubtitle = 'ملخص الأداء';             // اختياري
require __DIR__ . '/../includes/header.php';
?>

<!-- اكتب محتوى الصفحة هنا (HTML + Bootstrap) -->
<div class="card"><div class="card-body">
  محتوى التقارير
</div></div>

<?php require __DIR__ . '/../includes/footer.php'; ?>
----------------------------------------------------------------

   ملاحظة: إذا كانت الصفحة في الجذر (بجانب index.php) فاستخدم المسارات
   بدون "/../" :   require __DIR__ . '/includes/bootstrap.php';

الخطوة 2) افتح config/menu.php وأضف سطرًا قبل نهاية المصفوفة:

   ['label' => 'التقارير', 'icon' => 'bi-bar-chart', 'url' => 'reports/index.php', 'roles' => ['admin', 'registrar']],

الخطوة 3) حدّث المتصفح — ستظهر القائمة في جميع الصفحات لمن له صلاحية،
          ومن ليس له صلاحية يرى رسالة "غير مصرّح" إن فتح الرابط مباشرة.


------------------------------------------------------------------
ثانيًا: إضافة قائمة منسدلة جديدة (مجموعة)
------------------------------------------------------------------

   ['label' => 'المالية', 'icon' => 'bi-cash-coin', 'roles' => ['admin', 'registrar'], 'children' => [
       ['label' => 'الرسوم الدراسية', 'icon' => 'bi-receipt',  'url' => 'finance/fees.php'],
       ['label' => 'المدفوعات',       'icon' => 'bi-wallet2',  'url' => 'finance/payments.php'],
       ['label' => 'كشف حساب طالب',   'icon' => 'bi-person-lines-fill', 'url' => 'finance/statement.php', 'roles' => ['student']],
   ]],

   - العناصر الفرعية ترث صلاحية المجموعة ('roles' في السطر الأول)
     إن لم تحدد لها صلاحية خاصة.
   - إن حددت 'roles' لعنصر فرعي فهي التي تُطبَّق عليه.
   - المجموعة التي لا يوجد فيها أي عنصر مسموح للمستخدم لا تظهر له.


------------------------------------------------------------------
ثالثًا: إضافة عنصر داخل قائمة منسدلة موجودة
------------------------------------------------------------------

أضف سطرًا داخل 'children' للمجموعة المطلوبة، مثال داخل "الطلاب":

   ['label' => 'استيراد طلاب', 'icon' => 'bi-upload', 'url' => 'students/import.php', 'roles' => ['admin']],


------------------------------------------------------------------
رابعًا: صفحة محمية لا تظهر في القائمة
------------------------------------------------------------------

مثل صفحة "تعديل" أو "عرض تفاصيل" تُفتح من زر داخل جدول.
أضف 'show' => false:

   ['label' => 'تفاصيل طالب', 'url' => 'students/view.php', 'roles' => ['admin','registrar','teacher'], 'show' => false],

وضعها داخل 'children' لأي مجموعة. تبقى محمية لكنها لا تظهر في القائمة.


------------------------------------------------------------------
خامسًا: شرح حقول العنصر
------------------------------------------------------------------

  label     النص الظاهر في القائمة                         (مطلوب)
  url       مسار الصفحة نسبةً لجذر المشروع               (مطلوب للصفحات)
  icon      اسم أيقونة من Bootstrap Icons                  (اختياري)
  roles     الأدوار المسموح لها                            (اختياري)
              - بدون الحقل  = أي مستخدم مسجّل دخول
              - ['*']       = أي مستخدم مسجّل دخول
              - ['admin','teacher'] = هذان الدوران فقط
  children  قائمة عناصر فرعية = قائمة منسدلة              (اختياري)
  show      false = حماية الصفحة دون إظهارها في القائمة    (اختياري)

الأدوار المتاحة حاليًا:  admin  |  registrar  |  teacher  |  student

الأيقونات: https://icons.getbootstrap.com  (انسخ اسم الأيقونة مثل bi-gear)


------------------------------------------------------------------
سادسًا: صفحة بصلاحيات غير مدرجة في القائمة (بدون سطر في menu.php)
------------------------------------------------------------------

يمكن تحديد الصلاحية يدويًا داخل الصفحة نفسها:

   guard(['admin']);

وإذا كتبت guard(); فقط لصفحة غير موجودة في menu.php فهي متاحة لأي مستخدم
مسجّل دخول.  لذلك الأفضل دائمًا إدراج الصفحة في menu.php (ولو بـ 'show' => false).


------------------------------------------------------------------
سابعًا: إظهار/إخفاء أزرار داخل الصفحة حسب الدور
------------------------------------------------------------------

   <?php if (role_allowed(['admin', 'registrar'], current_user()['role'])): ?>
       <a href="<?= e(url('students/add.php')) ?>" class="btn btn-success">إضافة</a>
   <?php endif; ?>

تنبيه: إخفاء الزر لا يكفي للحماية. تأكد أن الصفحة التي يفتحها الزر
محمية أيضًا بـ guard() وأن عملية الحفظ نفسها (POST) داخل صفحة محمية.


------------------------------------------------------------------
ثامنًا: إضافة دور جديد (مثل "ولي أمر")
------------------------------------------------------------------

1) في config/config.php أضف الدور في 'roles' وفي 'role_badges':
      'roles'       => [ ... , 'parent' => 'ولي أمر' ],
      'role_badges' => [ ... , 'parent' => '' ],

2) في جدول المستخدمين (قاعدة البيانات) خزّن القيمة  parent  في عمود الدور.

3) في config/menu.php استخدم 'parent' ضمن 'roles' للصفحات المناسبة.


------------------------------------------------------------------
تاسعًا: روابط وأمان — عند كتابة الصفحات
------------------------------------------------------------------

  - الروابط:      <a href="<?= e(url('students/add.php')) ?>">
  - أي نص يُطبع:  <?= e($value) ?>              (حماية XSS)
  - أي نموذج POST: ضع <?= csrf_field() ?> داخله، وفي أول المعالجة:
                    if (!csrf_verify()) { /* ارفض الطلب */ }
  - استعلامات قاعدة البيانات: استخدم PDO prepared statements دائمًا.


------------------------------------------------------------------
قائمة التحقق بعد كل إضافة
------------------------------------------------------------------

  [ ] الصفحة تبدأ بـ guard();
  [ ] السطر مضاف في config/menu.php والمسار 'url' صحيح (حساس لحالة الأحرف)
  [ ] الفاصلة "," في نهاية السطر الجديد، والأقواس [] متطابقة
  [ ] جرّبت الدخول بكل دور: يظهر لمن له صلاحية ويختفي عن غيره
  [ ] فتحت رابط الصفحة مباشرة بدور غير مسموح فظهرت "غير مصرّح"
  [ ] فتحت رابط الصفحة دون تسجيل دخول فتحوّلت إلى login.php


------------------------------------------------------------------
حل المشاكل الشائعة
------------------------------------------------------------------

  القائمة لا تظهر          ← تأكد من الدور في 'roles' وأن المستخدم يحمل هذا الدور.
  الصفحة بيضاء             ← فعّل عرض الأخطاء مؤقتًا أو راجع سجل أخطاء PHP
                             (غالبًا فاصلة أو قوس ناقص في menu.php).
  القائمة لا تتلوّن "نشطة" ← تأكد أن 'url' يطابق مسار الملف تمامًا
                             (مثال: reports/index.php).
  الصفحة تفتح لمن لا يحق له← تأكد من وجود guard(); في أول الملف وأن الصفحة
                             مدرجة في menu.php بنفس مسار 'url'.
  الروابط خاطئة            ← إن كان النظام داخل مجلد فرعي اضبط 'base_url'
                             في config/config.php (مثل '/sis').
==================================================================


------------------------------------------------------------------
ملحق: تغيير اللوغو
------------------------------------------------------------------

1) ضع ملف الصورة داخل المجلد  assets/img/  (مثال: logo.png)
   - يفضّل PNG بخلفية شفافة أو SVG، بارتفاع لا يقل عن 80 بكسل.
2) في config/config.php غيّر:
      'logo' => 'assets/img/logo.png',
3) يظهر اللوغو تلقائيًا في الشريط العلوي وفي صفحة تسجيل الدخول.
   إن تركت الحقل فارغًا أو كان الملف غير موجود تظهر الأيقونة الافتراضية.
